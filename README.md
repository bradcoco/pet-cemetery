# 星屿 · 宠物纪念多端应用

一套 TypeScript + WXML + Less 代码，沿用微信官方多端框架。支持中国分省地图探访、地图立碑、在世/离世宠物档案、单层宠物档案、私密时光笔记、每日物品补给与赠礼、家庭后院家园。

## 运行

1. 在微信开发者工具中打开**本项目根目录**，不要只打开 `miniprogram/`。
2. 执行 `npm install`，开发者工具自动使用项目配置里的 TypeScript / Less 编译插件。
3. 点击编译。切换微信、iOS、Android 或鸿蒙目标时，继续使用现有多端项目。
4. `npm test` 检查 TypeScript、Less、路由资源、日期与坐标验证、隐私边界、柜位、照片归属和笔记保存，以及虚拟库存和编号分配的事务流程。

## 已实现

- **中国分省地图首页**：探索页仅显示地图探访，物品库存与签到保留在我的主页。初始展示真实省界绘制的中国全图，支持双指或加减按钮放大（1–5 倍）、拖动、恢复全貌；点击省份进入该省具体地图，右上角“返回”回到全国。不提供省份文字按钮列表、下拉选择器或密度指标。同坐标多个宠物可点开分别探访，无原生地图时回退到可点击的离线省图；示例点位明确标注。
- **统一隐私设置**：我的主页个人资料下方，以及本人公开主页，提供“隐私设置”入口。集中管理家园公开、总览笔记公开、每位宠物的资料公开、笔记本启用和笔记公开范围；修改即时保存，保留旧设置，不做默认批量公开。每本笔记提供“共写成员与邀请”直达现有成员管理，页面上方可直接进入普通访客预览。旧家园开关、笔记公开开关和已有档案编辑开关已收拢为状态与跳转；新建宠物保留首次选择。隐私写入只允许主人更新三个指定字段，不会用列表中的简化资料覆盖完整照片/故事/编号/库存。档案编辑保存通过 `preservePrivacy` 不写入隐私字段，与集中设置互不覆盖。库存始终私密，昵称头像与留言板遵循原有公开规则，不添加无效开关。
- **家园公开到主页**：统一“隐私设置”页提供家园“公开到主页”开关，默认私密；家园是否公开只在隐私设置里调整，家园卡片不再另加可见范围说明；开启后公开主页和访客预览展示后院、散步伙伴和纪念区。仅展示已放置且宠物资料设为公开的伙伴，私密、已删除或未放置的宠物不会出现在家园数据和数量中。公开家园只返回场景位置、名称、动物形象和单张封面，不带完整故事、库存或笔记权限。访客可点开公开档案，不能进入宠物仓、放置或收回伙伴；关闭公开不改变本人布局。公开开关保存在现有 `cabinets.gardenPrivacy`，布局、排序和书架设置事务保存时保留该字段。本机可预览效果，跨设备探访需配置并部署微信云开发。
- **家庭后院家园**：进入底部“我的主页”，点击个人资料下方的“我的家园”卡片展开后院，场景包含小屋、围栏、草坪、玩具与独立纪念花园。宠物仓仅展示自己的档案，支持全部 / 现存 / 已故三种模式；在世伙伴可取出后点击草坪摆放，会自动在活动区走动，并支持摸摸、追球陪玩、挪位置、查看档案和收回。离世伙伴可安放到纪念墓区，横向滑动查看墓碑、点击探访或收回纪念物；不要求先在地图立碑。家园摆放会保存，散步轨迹属于当前会话；隐藏页面和离开家园时停止计时器，已在活动区的伙伴变为离世状态后会归入纪念区。
- **地图立碑**：原生地图拖动、缩放、点击选点、搜索地点；不支持地图的端可使用经纬度选址。国内原生地图坐标为 GCJ02，按省归属统计时转换为省界数据所用的 WGS84 坐标。
- **宠物纪念**：名字、类型、出生日期、伙伴状态、离开日期（离世宠物）、品种、碑文、故事、最多 9 张照片；五种纪念碑样式（月光拱门 / 一颗星星 / 花间小憩 / 爱心纪念 / 仅用照片）；公开或私密，默认私密。支持编辑、删除、照片预览。在世宠物可先登记档案，不必设立墓碑；离世宠物也可暂不立碑。
- **墓碑定制与标记**：档案确认步骤选择样式，可独立上传/更换标记照片，不占相册九张上限；未单独上传时使用相册首张，仅照片样式必须有照片。实时预览外观与最多 80 字镌刻文字；详情、家园纪念区和省内地图使用所选样式与照片。地图 Canvas 导出失败时保留同款静态标记，Canvas 地图直接绘制照片标记。墓碑卡片下并排展示“宠物档案”和“宠物笔记”：档案打开同一宠物的阅读视图，展示基本资料、故事与相册，可返回墓碑；笔记按公开性与启用状态开放跳转，无权阅读或未展示时保留状态提示卡。访客预览在档案、墓碑和笔记之间跳转保留只读身份。创建时仍可选择是否贴上宠物笔记入口，开关只控制入口展示，不创建笔记或改变任何公开/私密权限；关闭笔记本或访客无阅读权限时不提供跳转，显示未开启或 🔒 未公开状态。旧档案保持原样式与笔记入口。标记照片使用现有持久文件与云端归属验证，列表和详情均签发可访问链接；不新增数据集合。
- **宠物档案**：自己登记的宠物自动收录，上方宠物货架展示带照片或 emoji 头像的精灵球，下方保留一层笔记本书架，仅展示已开启笔记本的宠物。上方精灵球货架始终保留全部宠物，关闭笔记本的伙伴可从精灵球进入统一隐私设置重新开启。两个架子共用全部 / 现存 / 已故三个 tab 和同一顺序；点击“调整顺序”后左右移动，分类内排序保留其他分类的位置，重进页面仍然生效。点击精灵球可打开笔记、编辑资料、标记已故或复活；全部是筛选范围，不是宠物状态。
- **状态纠正与复活占位**：标记已故前二次确认，离开日期默认今天，可在资料中修改。已故伙伴恢复为现存时，先弹出“看广告复活”占位确认，取消不修改，确认后恢复；编辑资料中的恢复操作也有同样提示。当前未接入或播放真实广告。状态切换保留原编号、完整照片、故事、礼物与笔记；复活清除离开日期和地图墓碑信息，可回宠物仓重新放置到家园。
- **笔记本开关与公开范围**：新宠物登记的确认步骤可选择初始笔记本与公开范围；已有宠物统一在我的主页的“隐私设置”中管理。档案编辑仅显示当前范围与跳转入口，不再重复放置开关。关闭控制整本笔记的创建与展示，不是自动生成单页；不会删除已有记录或共写成员，重新开启后可继续使用。旧宠物默认已开启、私密，新宠物默认开启并设为私密。关闭期间主人、成员和访客均不能从笔记接口访问或写入，邀请链接也暂停，好友共写列表不显示该本。笔记范围独立于宠物档案公开范围；公开本的全部记录可只读浏览，但不会开放完整宠物私密资料。转为私密后，非成员无法继续通过接口读取；受邀好友仍可共写。私密封面、笔记页和入口标有 🔒；总览本默认私密，也可由主人在统一隐私设置中改为公开只读。
- **笔记首页设置与标签**：笔记封面右上方“笔记设置”管理标签和共写成员，可见范围显示状态并跳转统一隐私设置；成员邀请、移除及停止邀请码集中在“成员设置”。单宠和总览均支持独立设置，统一隐私设置修改单宠笔记公开性后，笔记和档案编辑的状态说明同步更新，仅修改笔记字段。每本最多 30 个标签、名称 1～20 字，由主人新增/删除；记录可从该本的已有标签中多选最多 10 个，共写好友也能选择。首页支持按标签筛选，并与标题、正文、日期和标签名文字搜索组合使用。删除标签只移除分类，不删除记录；同名重建使用新编号，不会重新关联旧记录。标签按笔记本隔离，云端与记录写入使用事务校验；旧记录无标签仍可正常读写，旧客户端编辑省略标签时保留有效分类。
- **笔记本封面与动物形象**：封面显示宠物名称和首张上传照片；没有照片时使用选择的内置动物 emoji，未选择时按物种显示默认形象。支持 26 种 emoji，登记和编辑均可选择，并保存到宠物档案与家园形象。
- **总览记事本**：书架角落固定保留一本“全体伙伴”笔记，用于记录宠物群体的共同日常、照顾安排与成长故事。和单宠笔记分开存储，均支持日期、文字、照片、编辑、删除和本机草稿。总览笔记复用 `notes` 集合的保留标识 `__overview__`，通过可信笔记本主人身份隔离。
- **时光笔记与好友共写**：单宠与总览笔记默认私藏，均可独立设为公开只读；主人在笔记内点“邀请好友”，可生成有效 7 天的随机邀请码，复制或通过微信卡片分享；好友输入邀请码或打开分享后，先查看说明，再主动接受邀请。加入者可查看该本的旧记录和新记录，新建文字/照片笔记、编辑及删除自己写的记录；主人可删除本内任何记录、移除好友或停止新邀请。每本最多 20 位好友，笔记上显示作者。我的主页收录“好友共写笔记”，重进应用仍可访问；其他私密档案与宠物资料不会因此开放。草稿按笔记本区分，共写总览不会混入好友自己的总览。
- **共写权限与存储**：`notebookShares` 保存可信主人、对应宠物或总览标识、成员及邀请码；邀请与写入通过事务再次校验权限。移除成员后，共写权限即时失效；私密本拒绝后续访问，公开本仍可只读，即使记录是被移除者自己所写也不能再编辑或删除，已写记录保留；停止邀请码不移除已有成员。邀请码被停止或到期后不能加入，现有成员仍可访问。`notes._openid` 继续表示笔记本主人以兼容已有记录，新增 `authorId` 记录可信作者，仅后端使用，不返回原始账户标识；无 `authorId` 的旧笔记视为主人所写。笔记编辑只接受作者自己的上传照片。
- **每日签到**：我的主页、公开个人主页和礼物盒均可签到，展示连续签到天数和当天积分。第一天获得 30 积分，之后每连续签到一天再加 10，不按周重置；中断后下次从 30 积分重新开始。按北京时间每日零点切换，每日只能签到一次；不补发未签到日的奖励，积分可累积。旧库存与当日领取状态保留，当天已经签到的旧记录不会再补发物品或积分，旧记录没有连签天数时以最后一次领取为第 1 天。云端通过服务器时间和事务防止重复领取，不接受客户端指定签到日期、连签天数或积分数量。
- **物品与积分**：我的物品共 13 种，复用已有鲜花和小骨头，新增永恒烛光、纪念花园、宠物奶泡、纪念蜡烛、爪印爱心、天使之翼、玫瑰、彩虹桥、爱心气球，并保留鱼干、罐头。使用相近 emoji，所有物品的单件积分互不相同；库存卡展示可用积分、连续签到天数、单件兑换价和余额。签到只增加可用积分，积分可按标价兑换成物品；赠送只扣 1 件库存，收到的心意按礼物数量汇总价值。数值集中在 `miniprogram/utils/items.ts` 的 `ITEMS` 中，可直接调整。兑换价格由服务端按物品表计算，忽略客户端传入的价格。原有四种物品钱包和收礼数据自动补齐新键；缺少积分字段的旧钱包从 0 分开始。
- **用户主页与赠礼**：主页展示公开的在世/离世宠物。墓碑可收鲜花、烛光、花园、蜡烛、天使之翼、玫瑰、彩虹桥；在世狗狗可收小骨头和奶泡，猫咪可收小鱼干，所有在世宠物可收小罐头。爪印爱心和爱心气球可赠给在世宠物或墓碑。详情和公开主页展示实际收到的礼物与心意价值。每次赠送扣 1 件库存，计入宠物收到的礼物；接收的礼物不会变成主人的可再赠库存。库存仅本人可见。余额不足、物种不匹配、对方私密均不能赠送，云端事务与请求编号防止重复扣除。
- **专属 No.**：六位顺序号从 `000000` 开始，删除不回收，编辑不改变，首次登记展示旋转动画编号卡。本机模式编号只在本设备内有效；微信云端模式由全局计数器与宠物创建在同一事务中分配，全软件共用顺序，不接受客户端指定编号。六位编号上限 `999999`，到达后拒绝继续录入，不截断或绕回。
- **访客视角预览**：我的主页个人资料下方提供入口，按普通、未受邀访客的公开权限展示本人主页；私密宠物不进入列表或数量统计，隐藏主人库存、签到、编辑和私密笔记入口；已开启公开的家园也会按相同规则展示。继续打开宠物详情、公开笔记时保留预览，公开记录不可编辑，私密笔记即使主人或成员也不可在此模式打开。赠礼按钮仅说明访客操作，不扣库存；退出预览回到我的主页。预览不修改公开性，也不产生礼物或笔记写入。本机预览展示本设备数据设为公开后的样式，不向其他设备发布。
- **主页留言板**：我的主页和公开主页共用同一块公开留言板，支持 1～300 字留言、每页 10 条的“查看更多”，最新在前。点击留言弹出留言者头像与昵称名片，可进入对方主页；头像和昵称随账户资料更新，未设置头像时显示默认形象。作者可删除自己的留言，主页主人可清理本页留言，其他人不能删除。云端作者取自可信登录上下文，不接受伪造身份；发布请求幂等，重复重试不重复落库。访客预览展示留言与名片，但不能发布或删除，进入留言者主页时保留预览。当前本机模式仅保存设备内留言，跨设备互访需启用微信云开发；App 端共享账户尚未接入。
- **资料**：昵称、头像，多只宠物的统一档案管理。

## 存储与账户

默认 `miniprogram/config.ts` 中 `CLOUD_ENV` 为空，**所有端均可先体验本机完整流程**。照片通过持久文件 API 保存；档案、家园摆放、笔记、笔记设置、留言与草稿保存在设备中。卸载、清理应用数据或更换设备可能丢失内容。本机的“公开”是可见范围设置，不会发布到其他设备。首页示例均为虚构，不会进入个人宠物档案。

已经提供微信云开发账户与后端，启用方式：

1. 创建云开发环境。
2. 创建 `memorials`、`profiles`、`cabinets`、`notes`、`notebookShares`、`wallets`、`counters`、`giftEvents`、`guestbookMessages` 九个集合，**客户端读写均设置为禁止**。已有环境升级也要先创建 `notebookShares`、`guestbookMessages` 并重新部署云函数。笔记标签和总览本公开范围保存在 `notebookShares` 内；邀请操作保留已有设置，无需新集合。家园布局与宠物顺序保存在当前用户的 `cabinets` 文档内的 `garden` / `petOrder` 字段；与柜位保存通过事务合并，互不覆盖。
3. 云存储使用“仅创建者可读写”权限，保持私密读取。客户端只上传自己的文件；云函数在通过主人/公开权限校验后签发图片临时地址。
4. 在开发者工具中右键 `cloudfunctions/memorial`，选择“上传并部署：云端安装依赖”。函数运行环境选择支持 Node.js 18 或更高版本的环境。函数目录含独立 `package.json` 与锁文件。
5. 在 `miniprogram/config.ts` 填入环境 ID，重新编译微信端。
6. 为 `memorials.no` 建立唯一索引。首次启用时 `counters` 保持为空，第一次登记会自动创建 `pet-sequence` 并签发 `000000`；不要删除或重置该计数文档。
7. 根据控制台提示为纪念列表和笔记列表建立查询索引：纪念按 `_openid` / `privacy` 过滤，按 `createdAt`、`_id` 降序；笔记按 `memorialId`、`_openid` 过滤，按 `date`、`createdAt` 降序。公开主页按 `profiles.publicId` 查找、按主人与公开权限筛选宠物。共写邀请按 `notebookShares.inviteCode` 查找，好友列表按 `memberIds` 数组包含过滤、`_id` 升序查询；留言按 `guestbookMessages.user` 过滤、`createdAt` / `_id` 降序查询；按云端提示补齐索引。

云函数通过可信微信上下文识别主人和作者，不接受客户端提供的主人身份。公开纪念可由访客读取；修改和删除宠物、档案柜、家园须为主人；公开笔记允许访客只读，私密笔记仅主人和已加入的成员可读；写入仅主人或共写成员可用，并按作者区分编辑权限。每日领取、赠礼扣库存和全局编号均使用事务；赠礼请求与创建请求均支持幂等重试。图片临时地址最长有效 10 分钟，已签发的地址在过期前不会因为随后改成私密或移除成员而立即失效。

**本机数据不会自动迁移到云端。** 在启用云服务前保留设备内数据，云端纪念需另行创建或后续增加显式迁移。当前删除档案不会回收已经上传的云存储文件；废弃上传、删除档案遗留的笔记与赠礼数据，需要后续配置生命周期清理。

- 保留 `project.config.json` 的 `projectArchitecture: multiPlatform`、`project.miniapp.json` 和转换生成的 `app.miniapp.json`。
